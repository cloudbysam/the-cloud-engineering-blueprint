# Europe & Germany Remote Boards (Work from Anywhere / CET Time Zone)

Platforms for companies operating in European time zones (CET/CEST/GMT) that offer "Work from Anywhere" or contract-based employment across Europe and Germany.

| Platform | URL | Region / Focus | Notes |
| :--- | :--- | :--- | :--- |
| **Remotive Germany** | `remotive.com/remote-germany-jobs` | **Germany / Worldwide** | Filters German companies hiring globally via B2B/Contract |
| **Flexa Careers** | `flexa.careers/jobs/categories/germany-remote` | **Germany / Anywhere** | Filters companies with 100% "Work from Anywhere" policies |
| **Working Nomads Germany** | `workingnomads.com/remote-germany-jobs` | **Germany / Global** | Remote roles hosted by German companies with worldwide coverage |
| **GermanTechJobs** | `germantechjobs.de` | **Germany / Hybrid / Remote** | *Filter by "100% Remote"* (Check individual listing for borderless) |
| **EuropeRemotely** | `europeremotely.com` | **Europe / Worldwide** | Tech roles operating on European time zones with no location lock |
| **EU-Startups** | `eu-startups.com/jobs` | **Europe / Anywhere** | High percentage of borderless, remote-first European startups |
| **MeetFrank** | `meetfrank.com` | **EU / Global** | Anonymous job search app with a heavy focus on European tech |
